# TAUM Brand Palette — extracted from the building mural
*Source: mural-photo.jpg (front of 392 2nd Street). Sampled 2026-07-19.*

The mural: a flock of stylized birds — one carrying an olive branch (the peace dove Abby wants in the new logo) — cooperatively building a large coral-orange nest against a sky-aqua brick wall. Great brand story: "many hands building a home together."

| Name | Hex | Suggested role |
|---|---|---|
| Sky aqua | `#7AD4E8` | Hero backgrounds, section tints |
| Pale aqua | `#A8E4F0` | Alternating section bands |
| Nest coral | `#F0765C` | Donate button, primary CTAs |
| Warm peach | `#F2A98E` | Card fills, hover states |
| Wing magenta | `#A24E97` | Secondary accent, links |
| Feather indigo | `#2A3060` | Headings, footer, body text |
| Dove cream | `#F2EFCF` | Page background, warm white |
| Olive branch | `#7C8C3F` | Garden campaign, success states |

## Usage notes
- Bright/light/inviting = cream or white page base, aqua bands, coral reserved for action buttons so "Donate" always pops.
- Indigo replaces black for text — softer, still passes contrast on cream/white.
- Check WCAG contrast before shipping: coral `#F0765C` on white fails AA for small text — use it for large buttons/headings only, or darken to ~#D85A3E for text links.
- Magenta and olive are garnish, not structure — one or two appearances per page.
- Peace dove + olive branch motif (center-left of mural) is the anchor for the new logo Abby wants.
